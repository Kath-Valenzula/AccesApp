# AccesApp S2

Proyecto base Android con Jetpack Compose, Material 3 y Navigation.

## Matriz de versiones
Android Studio 2024.2.1 (Ladybug) | AGP 8.6.1 | Gradle wrapper 8.7 | Kotlin 2.0.21 | JDK 17 | compileSdk 34 | targetSdk 34 | minSdk 21

## Cómo ejecutar
1. Abrir en Android Studio.
2. Sincronizar Gradle.
3. Ejecutar en emulador o dispositivo.
